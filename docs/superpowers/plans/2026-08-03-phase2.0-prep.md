## Task 0 — the 3-consumer verification harness (run FIRST, keep the output)

Every deletion in PR-C is gated on this script returning zero real consumers. Write it
once; re-run it per module. It encodes every trap found in Phase 0/1 and this review.

Write to `/tmp/claude-502/.../consumers.sh` (scratch, not committed):

```bash
#!/usr/bin/env bash
# usage: consumers.sh <module_name>
set -uo pipefail
M="$1"
CODE=/Users/eranagmon/code

# Canonical checkouts ONLY. Excludes sibling worktrees (vwb-*, v2e-*, v2ecoli--* other
# than --main, vivarium-workbench--*, pbg-superpowers--*) and picks ONE per repo family.
REPOS=(
  "$CODE/pbg-superpowers"            # the plugin itself
  "$CODE/vivarium-workbench-main"    # the workbench
  "$CODE/v2ecoli--main"              # downstream #1
  "$CODE/pbg-autopoiesis"            # downstream #2
  "$CODE/viva-human-atlas"
  "$CODE/pbg-biomodels--main"
  "$CODE/viva-munk"
  "$CODE/viva-fenics"
  "$CODE/investigation-contracts"
)
# NOTE: sms-ecoli is a FORK of v2ecoli (identical paths + line numbers). Counting both
# double-counts. It is checked separately, below, ONLY to catch fork-only divergence.

EXCL='/\.venv/|site-packages|/node_modules/|/out/|__pycache__'

echo "### module: $M"
echo "--- 1. IMPORTS (both aliases: viva_superpowers AND pbg_superpowers)"
for r in "${REPOS[@]}"; do
  grep -rnE "(from|import) (viva|pbg)_superpowers(\.$M\b| import $M\b)" "$r" \
    --include='*.py' --include='*.ipynb' 2>/dev/null | grep -vE "$EXCL" \
    | grep -v "_superpowers/$M.py:" | sed "s|^$CODE/||"
done

echo "--- 2. CLI: python -m invocations (invisible to import greps)"
for r in "${REPOS[@]}"; do
  grep -rnE "python3? -m (viva|pbg)_superpowers\.$M\b" "$r" \
    --include='*.py' --include='*.sh' --include='*.md' --include='*.yml' --include='*.yaml' \
    2>/dev/null | grep -vE "$EXCL" | sed "s|^$CODE/||"
done

echo "--- 3. console_scripts declared for this module"
grep -nE "= \"(viva|pbg)_superpowers\.$M:" "$CODE/pbg-superpowers/pyproject.toml"
echo "--- 3b. those script NAMES referenced anywhere"
for s in $(grep -oE "^[a-z-]+ = \"(viva|pbg)_superpowers\.$M:" "$CODE/pbg-superpowers/pyproject.toml" | cut -d' ' -f1); do
  for r in "${REPOS[@]}"; do
    grep -rn "\b$s\b" "$r" --include='*.md' --include='*.sh' --include='*.yml' \
      --include='*.yaml' --include='*.toml' --include='*.py' 2>/dev/null \
      | grep -vE "$EXCL" | grep -v 'pbg-superpowers/pyproject.toml' | sed "s|^$CODE/||"
  done
done

echo "--- 4. SKILL.md prose (an agent that reads 'prefer X' IS a consumer)"
grep -rn "$M" "$CODE/pbg-superpowers/skills" 2>/dev/null | sed "s|^$CODE/||"

echo "--- 5. GENERATED / PUBLISHED artifacts (reports, notebooks, emitted source)"
for r in "${REPOS[@]}"; do
  grep -rn "$M" "$r" --include='*.ipynb' --include='*.html' 2>/dev/null \
    | grep -E "(viva|pbg)_superpowers" | grep -vE "$EXCL" | sed "s|^$CODE/||" | head -5
done

echo "--- 6. FORK CHECK: sms-ecoli hits NOT present in v2ecoli--main"
diff <(grep -rn "$M" "$CODE/v2ecoli--main" --include='*.py' 2>/dev/null \
        | grep -E "(viva|pbg)_superpowers" | sed 's|.*/||' | sort) \
     <(grep -rn "$M" "$CODE/sms-ecoli" --include='*.py' 2>/dev/null \
        | grep -E "(viva|pbg)_superpowers" | sed 's|.*/||' | sort) \
  | grep '^>' || echo "(no fork-only divergence)"
echo
```

**Acceptance for a delete:** sections 1, 2, 3b, 5, 6 all empty; section 4 either empty or
its lines are edited in the same commit (`plot_style`, `calibration_sweep`).

- v2ecoli has its **own** `runner.py`, `provenance.py`, and `scripts/backfill_*` — never
  grep for bare module names, always anchor on `viva_superpowers.`/`pbg_superpowers.`.
- `~/code` contains ~25 sibling worktrees (`vwb-*`, `v2e-*`, `v2ecoli--*`,
  `vivarium-workbench--*`). Including them inflates every count several-fold.
